# Royal Bull Capital — Enterprise Deployment Guide

## 🚀 1. One-Click Deployment via Render Blueprint (Recommended)

This repository includes a production-ready `render.yaml` Blueprint specification that automatically provisions:
1. **`royal-bull-backend`**: FastAPI Web Service with automated migrations and seed bootstrap on startup.
2. **`royal-bull-frontend`**: React/Vite Static Site with global edge CDN distribution and SPA URL rewrites.
3. **`royal-bull-db`**: Managed PostgreSQL database with automated secure connection pooling.

### Steps to Deploy on Render:

1. **Push your code to GitHub or GitLab**:
   Ensure your repository includes `render.yaml` in the root folder.

2. **Open Render Dashboard**:
   - Go to [https://dashboard.render.com](https://dashboard.render.com)
   - Click the **"New +"** button in the top right corner.
   - Select **"Blueprint"**.

3. **Connect Your Repository**:
   - Select the GitHub/GitLab repository containing Royal Bull Capital.
   - Render will parse `render.yaml` and display the blueprint resources:
     - `royal-bull-backend` (Web Service, Python)
     - `royal-bull-frontend` (Static Site, Node/Vite)
     - `royal-bull-db` (PostgreSQL Database)

4. **Review Configuration & Deploy**:
   - Click **"Apply"**.
   - Render will automatically:
     - Create and provision the PostgreSQL database.
     - Build and launch the FastAPI backend service.
     - Generate a secure 256-bit `JWT_SECRET_KEY`.
     - Seed the baseline system rules and the superadmin account (`admin@royalbull.com` / `Admin123!`).
     - Build the frontend static bundle and wire the backend host to `VITE_API_URL`.

5. **Access Your Live Platform**:
   - Frontend: `https://royal-bull-frontend.onrender.com`
   - Backend API: `https://royal-bull-backend.onrender.com/api`
   - Healthcheck: `https://royal-bull-backend.onrender.com/health`

## 2. Environment Variables Reference

| Variable | Service | Description | Default / Example |
| :--- | :--- | :--- | :--- |
| `PORT` | Backend | HTTP port for Uvicorn | `10000` (Render default) |
| `DATABASE_URL` | Backend | PostgreSQL connection string | Linked automatically from `royal-bull-db` |
| `JWT_SECRET_KEY` | Backend | Cryptographic secret for signing auth tokens | Auto-generated by Render (`generateValue: true`) |
| `INITIAL_ADMIN_PASSWORD` | Backend | Password for root admin `admin@royalbull.com` | `Admin123!` |
| `ALLOWED_ORIGINS` | Backend | Allowed CORS origins (comma-separated or `*`) | `*` |
| `VITE_API_URL` | Frontend | Full URL or host of backend API | Injected from `royal-bull-backend` |

## 3. Alternative Deployment with Docker Compose (VPS / Dedicated Server)

1. Clone repository onto server:
```bash
git clone <repo_url> /opt/royalbull
cd /opt/royalbull
```

2. Review `.env` and `docker-compose.yml`.

3. Launch containers:
```bash
docker compose up -d --build
```

4. Verify health checks:
```bash
docker compose ps
curl http://localhost/api/health
```

## 4. Reverse Proxy & SSL (Certbot on VPS)

To attach a custom domain with HTTPS on a VPS:

```bash
sudo apt update && sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d app.royalbullcapital.com
```

## 5. Database Backup & Disaster Recovery

### Creating a Database Backup
```bash
pg_dump -U royalbull_user -h localhost -d royal_bull_capital -F c -b -v -f /backups/royalbull_backup_$(date +%Y%m%d_%H%M%S).dump
```

### Restoring from a Backup
```bash
pg_restore -U royalbull_user -h localhost -d royal_bull_capital -v -c /backups/royalbull_backup_YYYYMMDD_HHMMSS.dump
```
